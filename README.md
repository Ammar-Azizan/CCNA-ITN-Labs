# CCNA: Introduction to Networks — Lab Portfolio

This repository documents my practical lab work while studying **Cisco CCNA: Introduction to Networks (ITN)**.

The portfolio focuses on applying networking concepts through hands-on activities using **Cisco Packet Tracer**, with technical documentation covering network implementation, device configuration, verification, and key findings.

## 🎯 Objectives

- Strengthen my understanding of networking fundamentals through practical labs
- Develop hands-on experience with Cisco Packet Tracer and Cisco IOS
- Practice network configuration, verification, and troubleshooting
- Document technical implementations and key findings
- Build a structured networking portfolio
